# 📱 硬件信息 (Hardware Info)

一个极简、现代、美观的 Android 硬件参数检测工具。完全遵循 Google Material 3 设计规范开发，支持深/浅色模式智能自适应。

本项目采用 **“零 XML 布局方案”**，完全使用 Kotlin 动态构建卡片式原生 UI，性能强劲，体积轻量，绝无冗余代码。

---

## ✨ 核心功能与检测维度

*   **📱 设备基本信息**：品牌、机型、制造商、主板、硬件/设备代号。
*   **⚙️ 系统运行状态**：Android 版本、API 等级、安全补丁时间、内核版本、已运行时间。
*   **🧠 处理器 (CPU)**：支持的架构 (ABIs)、核心数量、最大频率、调度策略。
*   **💾 内存与存储**：RAM 总量/可用、内置闪存总量/可用。
*   **🖥️ 屏幕与 GPU**：物理分辨率、屏幕密度 (DPI)、刷新率、估算屏幕尺寸、OpenGL ES 版本。
*   **🔋 电池与电源**：实时电量、电池温度、电压、电池技术类型、健康状态。
*   **🌐 网络与连接**：当前网络类型 (Wi-Fi/移动网络)、NFC 支持状态、蓝牙支持状态。
*   **📡 传感器检测**：加速度、陀螺仪、磁力计、光线传感器支持状态，以及硬件传感器总数。

---

## 🎨 界面设计亮点

*   **Material 3 体验**：沉浸式状态栏与导航栏设计，高对比度的卡片排版。
*   **全自动深浅色适配**：无需手动设置，完美跟随系统切换高雅深色或清爽浅色主题。
*   **彩色小药丸指示器**：每个硬件分类卡片左侧均有动态色彩条，使视觉层次更加分明。

## 🛠️ 云端自动编译指南 (GitHub Actions)

本项目已经配置好自动化工作流，你不需要在本地安装任何 Android SDK：

1. 修改代码并 `git push` 推送至 GitHub。
2. 访问当前仓库的 **Actions** 页面。
3. 点击最新的 **Build Android APK** 工作流任务。
4. 编译完成后，拉到最底部，在 **Artifacts** 区域即可点击下载最新编译出来的 `hwinfo-v1.0` 安装包！
